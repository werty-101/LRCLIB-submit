<h1>Description</h1>

<p>Simplifies the process of submitting lyrics files (.lrc) to LRCLIB.</p>

<h2>Prerequisites</h2>

<ul>
    <li>Have ffmpeg installed. If you don't have it installed:</li>
    <ul>
        <li>Press Windows Key + R or Open Command Prompt on Windows</li>
        <li>type "winget install ffmpeg"</li>
    </ul>
    <li>An mp3 file of the song of your choice.</li>
    <li>Hope that something does not break.</li>
</ul>

<h2>Instructions</h2>

<ol>
    <li>Go to <a href="https://subtitletools.com/timed-lyrics-editor">Timed Lyrics Editor</a> and create a .lrc file. 
        Note: You only need to use the lyrics and syncer tab, do not add metadata</li>
    <li>Open up the tool and fill in all the spaces</li>
    <li>Click "Submit"</li>
</ol>
